Inspect plan JSON

A small lab. A complete evidence loop.

  1. Propose cases. Load curated cases, edit bounded JSON, or request a real NVIDIA model plan after configuring Nebius.
  2. Review the boundary. Only documented requests that exercise their named invariant are accepted.
  3. Execute the buggy fixture. Every case starts from a fresh ledger; inspect actual responses and state transitions.
  4. Apply fixture repairs and rerun. The same accepted cases test the fixed implementation, with a direct before/after comparison.

There is no arbitrary code execution and no production API target. Offline results are real fixture execution with curated cases, not model inference.

Connect Nebius when you are ready

  1. Create a Token Factory account and API key. Its current onboarding requires billing setup and a bank card; promotional credits and country access need verification.
  2. Copy .env.example to .env. Set backend-only NEBIUS_API_KEY and an explicit NEBIUS_MODEL_ID beginning nvidia/, then restart.
  3. Select “NVIDIA model via Nebius” and request a plan. Generation makes one bounded inference call; the default curated mode makes none.

Example model: nvidia/nemotron-3-super-120b-a12b. Availability in your account is unverified.
